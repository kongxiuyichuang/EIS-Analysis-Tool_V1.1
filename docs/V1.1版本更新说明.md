# EIS Analysis Tool V1.1 版本更新说明
## ——RBF 离散、自动选 λ 与 DRT-DOP/DRT-DDT 联合求解

**摘要**：V1.1 在经典 DRT/DCT/gDRT 基础上完成四项重要更新：① 引入径向基函数（RBF）离散，与国际经典工具（pyDRTtools/DearEIS/pyimpspec）对标；② 引入 GCV / mGCV / L 曲线三种正则化参数自动选择；③ 为抑制扩散阻抗在 DRT 中产生的伪峰，新增 DRT-DOP、DRT-DDT 联合求解（DRT-DOP 针对半无限扩散、DRT-DDT 针对有限扩散）；④ 新增纯 DOP 与纯 DDT 独立分析，可单独解析仅含扩散部分的频谱并给出扩散常数分布。本文给出各更新内容的数学原理、实现要点与优势。

## 二、更新功能的原因

### 2.1 引入 RBF：与经典对标
经典 DRT 多用分段线性（PWL）离散，谱线不够光滑、分辨率受网格限制。RBF 离散化（Wan et al. 2015 [3]）将 $g(\ln\tau)$ 展开为光滑基函数叠加，正则化矩阵取基函数导数的**解析内积**（Gram 矩阵），**与 pyDRTtools / DearEIS / pyimpspec 等国际工具保持同一方法学基线**，便于交叉验证与学术对标。

### 2.2 引入自动选 λ
Tikhonov 正则化参数 λ 决定解的平滑度，手动选择主观且耗时，数据量级不同还会使有效 λ 偏移。引入 GCV / mGCV / L 曲线在 $[10^{-7},10^{0}]$ 内自动寻优，并在统计中展示实际值，兼顾客观性与可复现性（Maradesa et al. 2023 [12]）。

### 2.3 扩散伪峰问题：DRT-DOP 与 DRT-DDT
扩散阻抗在 DRT 反演中会以伪峰形式干扰 RC 过程归因（详见课题报告 [28]）：
- **半无限 Warburg**（$Z_W=A_W/\sqrt{j\omega}$）：复平面上无离散极点的分支连续谱，在 DRT 上呈幂律斜线/连续尾。**DRT-DOP** 以 $(j\omega)^\nu$ 分数阶核吸收该幂律，消除发散斜线、抑制伪峰；
- **有限空间/长度扩散（FSW/FLW）**：其 Mittag–Leffler 展开是"电容 + 无穷 RC 级数"或"等比收缩的 RC 伪峰簇"。**DRT-DDT** 用物理正确的扩散核族直接反演扩散时间分布，从根源上消除中频 Debye 伪峰。

### 2.4 纯 DDT：独立解析扩散
单独的 DDT 允许只对**含扩散部分的频谱**做反演，将不同扩散过程按扩散时间 $\tau_D$ 分解，得到**扩散常数的分布**——无需先剥离弛豫过程，适合纯扩散主导（如电极厚度、离子扩散系数分布）的研究场景。

## 三、RBF 离散方法与 λ 自动选择

### 3.1 RBF 离散的数学框架

将分布用 $n$ 个径向基函数展开：

$$g(\ln\tau)=\sum_{m=1}^{n}x_m\,\phi_m(\ln\tau),\qquad
\phi_m(\ln\tau)=\phi\!\big(\varepsilon(\ln\tau-\ln\tau_m)\big),\quad x_m\ge0$$

#### 3.1.1 基函数族（9 种，`RBF_TYPES`）

| 基函数 | $\phi(x)$ |
|:--|:--|
| Gaussian | $e^{-(\varepsilon x)^2}$ |
| C0 Matérn | $e^{-|\varepsilon x|}$ |
| C2 Matérn | $e^{-|\varepsilon x|}(1+|\varepsilon x|)$ |
| C4 / C6 Matérn | Matérn 高阶族（截断光滑） |
| Inverse Quadratic | $1/\big(1+(\varepsilon x)^2\big)$ |
| Inverse Quadric | $1/\sqrt{1+(\varepsilon x)^2}$ |
| Cauchy | $1/\big(1+|\varepsilon x|\big)$ |

#### 3.1.2 形状因子 $\varepsilon$ 的确定

- **FWHM 系数**（默认）：先解 $\phi(x)=\tfrac12$ 得半高全宽常数 $\mathrm{FWHM}_{\mathrm{coeff}}=2x_{1/2}$，再取
  $$\varepsilon=\frac{\mathrm{coeff}\cdot \mathrm{FWHM}_{\mathrm{coeff}}}{\bar\Delta},\qquad \bar\Delta=\mathrm{mean}\big(\Delta\ln\tau\big)$$
  即基宽 ≈ coeff 倍平均对数间距（默认 coeff=0.5）；
- **形状因子**：直接 $\varepsilon=\mathrm{coeff}$。

#### 3.1.3 响应矩阵（A 矩阵）

记 $u=\ln(\tau/\tau_m)$，矩阵元为基函数与核的卷积积分：

$$A_{\mathrm{re}}[p,n]=\int k_{\mathrm{re}}(\omega_p\tau_ne^u)\,\phi(u)\,du$$

- DRT 核：$k_{\mathrm{re}}=1/\big(1+(\omega\tau)^2e^{2u}\big)$，$k_{\mathrm{im}}=-\omega\tau e^u/\big(1+(\omega\tau)^2e^{2u}\big)$
- DCT 核（导纳空间）：$k_{\mathrm{re}}=(\omega\tau)^2e^{2u}/\big(1+(\omega\tau)^2e^{2u}\big)$，$k_{\mathrm{im}}=\omega\tau e^u/\big(1+\cdots\big)$

积分在自适应网格上数值进行：轻尾基（Gaussian/Matérn）取 $[-10/\varepsilon,10/\varepsilon]$，重尾基取 $[-60,60]$。

#### 3.1.4 正则化矩阵（M 矩阵）

惩罚 $k$ 阶导数的 $L^2$ 范数，取基函数导数的解析内积：

$$M_k[n,m]=\int\frac{d^k\phi_n}{d(\ln\tau)^k}\,\frac{d^k\phi_m}{d(\ln\tau)^k}\,d\ln\tau$$

Gaussian 等基有**闭式解**（如二阶高斯 $=\varepsilon^3(3-6a^2+a^4)e^{-a^2/2}\sqrt{\pi/2}$）。对数均匀网格下 M 为 **Toeplitz 矩阵**（只算首行），大幅加速；τ=1/f 非均匀配点时逐对暴力构造。

#### 3.1.5 系数→分布映射

求解得展开系数 $x$ 后，经 $g=\mathbf{B}x$（$\mathbf{B}[p,m]=\phi(\ln\tau_p^{\mathrm{map}}-\ln\tau_m)$）映射回谱线。

### 3.2 GCV / mGCV / L 曲线自动选 λ

统一在 $[10^{-7},10^{0}]$ 内以 **SLSQP** 优化 $\ln\lambda$。定义 $A_{\mathrm{G}}=A(A^\top A+\lambda M)^{-1}A^\top$：

- **GCV**（广义交叉验证）：
$$\mathrm{GCV}(\lambda)=\frac{\tfrac1n\|(I-A_G)Z\|^2}{\big(\tfrac1n\operatorname{tr}(I-A_G)\big)^2}$$
- **mGCV**（修正 GCV，缓解 GCV 过度平滑）：分母改为 $\operatorname{tr}(I-\rho A_G)$，$\rho=2$（$n\ge50$）或 $1.3$（$n<50$）
- **L 曲线**：最大化 log-log 域残差范数 vs 解范数曲线的曲率
$$\kappa(\lambda)=-\frac{\eta'\theta''-\eta''\theta'}{\big(\eta'^2+\theta'^2\big)^{3/2}},\qquad \eta=\|Ax-Z\|,\ \theta=\|Lx\|$$

自动方式下用户输入 λ 仅作初值（钳制到可行域），统计面板显示实际选取值。

## 四、DOP 与 DDT 的实现

### 4.1 DOP：相位角分布（phasance）

$$Z_{DOP}(\omega)=\int_{-1}^{1}\rho(\nu)\,(j\omega)^{\nu}\,d\nu$$

- **ν 网格**：默认两段拼接 $[-1,-0.4]\cup[0.4,1]$，**掏空 $\nu\approx0$**——因为 $(j\omega)^0=1$ 与 $R_\infty$ 完全共线，$|\nu|\ll1$ 的分数阶基在有限频窗内近乎平直，掏空可避免退化，把"电阻侧"交由独立的 `fit_ohmic` 处理
- **高斯基离散**（$\varepsilon_\nu=1/\Delta\nu$），响应矩阵元有 **erf 闭式**：
$$\Phi_{DOP}[m,n]=\frac{\sqrt{\pi}}{2\varepsilon_\nu}(j\omega_m)^{\nu_n}
e^{\frac{1}{4\varepsilon_\nu^2}(\ln j\omega_m)^2}
\operatorname{erf}\Big(\varepsilon_\nu(\nu-\nu_n)-\tfrac{\ln j\omega_m}{2\varepsilon_\nu}\Big)\Big|_{\nu=-1}^{1}$$
- 求值时 `predict_dop` 将拟合的 $R_\infty$ 以 δ 形式置于 $\nu=0$；图上 $\nu=-0.5$ 虚线对应理想 Warburg

### 4.2 DDT：扩散时间分布

$$Z_{DDT}(\omega)=\int q(\tau_D)\,Z_{\mathrm{ker}}(\omega,\tau_D)\,d\ln\tau_D,\qquad u=(j\omega\tau_D)^p$$

| 类型 | 核 $Z_{\mathrm{ker}}$ | 边界 |
|:--:|:--|:--|
| 1 | $\coth(u)/u$ | 开路（透射） |
| 2 | $I_0(u)/(uI_1(u))$ | 圆柱阻塞 |
| 3 | $\tanh(u)/u$ | 短路 |

三种核均做小 $u$ 级数与 $u\to\infty$ 渐近展开，保证 $0<p\le\tfrac12$ 数值稳定。支持三种模式：

- **1D 固定 $p=0.5$**（经典）；
- **`fit_ddt_p`**：标量 $p$ 在 $[0.05,0.5]$ 内以嵌套 QP 坐标下降优化
  $$p^*=\arg\min_{p'}\ \min_{x\ge0}\Big\{\tfrac12 x^\top P(p')x+q(p')^\top x\Big\}$$
- **2D 反常 DDT**：对 $(\tau_n,p_m)$ 节点，基函数为 $\tau_D$×$p$ 二维高斯基，用 **Gauss–Hermite 张量积求积**（每维 7 点）+ 二维查找表插值，$p_m+q$ 裁剪到 $[0,0.5]$；惩罚矩阵为可分离 Kronecker 组合 $M_k^{\tau}\otimes I_{n_p}+c_pI_{n_\tau}\otimes M_k^{(p)}$，输出 $\tau_D$–$p$ 热图及 p 边缘 $q(\tau_D)$ 曲线

### 4.3 联合求解框架（QPHB）

三者共享"离散化 → 凸 QP → QPHB 分层贝叶斯迭代"框架。QPHB 惩罚矩阵

$$\Lambda=\sum_{k=0}^{K-1}\lambda_0\,\omega_k\,\rho_k\,S_k^{\frac12}M_kS_k^{\frac12}$$

- $\lambda_0$（`l2_lambda_0`）：全局正则强度（顶层超超参，手动）
- $\omega_k$（`derivative_weights`）：$k$ 阶罚权重（固定）
- $\rho_k$：每阶全局导数强度（自动，Gamma 先验，负反馈更新 $\rho_k=\alpha_k^\rho/\big(x^\top M_kx/\mathrm{xmx\_norm}+\beta_k^\rho\big)$）
- $s_k$：**局部**惩罚尺度（自动；随 $x_i^2$ 增大而减小 → "峰锐利、尾光滑"）

数据先按 `rp_scale` 归一化（`coefficient_scale=rp_{est}/rp_{scale}`）。**各块（DRT/DOP/DDT）有独立 $s,\rho$ 超参**，故联合反演中引入 DOP/DDT 块不会"压垮" DRT 正则化。默认 `DRT_l2_λ0=140`、`DOP_l2_λ0=10`、`DDT_l2_λ0=1.0`——它们是各块的**绝对强度与块间分配**旋钮，与 legacy 单一 λ **无简单倍率关系**。

## 五、方法选择指引

| 谱特征 | 建议 | 原理 |
|:--|:--|:--|
| 纯多 RC 弛豫 | DRT | $g(\tau)$ 精确无伪峰 |
| 扩散 + 低频 $(j\omega)^p$ | **DRT-DOP** | DOP 吸收分数幂律，抑制发散斜线 |
| 扩散弧明显、需 $\tau_D$ | **DRT-DDT** | 物理正确扩散核族，消除中频 Debye 伪峰 |
| 反常扩散 $p\ne0.5$ | 2D DDT / `fit_ddt_p` | 释放反常指数自由度 |
| 纯扩散频谱 | **DDT（纯）** | 直接给出扩散常数分布 |
